# Hoa Nhà Lài

Trang demo bán hoa một trang, dùng HTML, CSS và JavaScript thuần.

## Xem nhanh

Mở `hoa.html` bằng trình duyệt. Cần Internet để tải font và ảnh minh họa từ Google Fonts/Unsplash.

## Cloudflare Pages

Chọn thư mục `hoanhalai` làm thư mục build output. Sau khi deploy, trang có thể mở ở `/hoa.html`; `_redirects` cũng tạo đường dẫn `/hoa`.

Sản phẩm, liên hệ và nội dung gửi đơn hiện là dữ liệu demo, chưa kết nối backend.
